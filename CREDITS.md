# Tiamat Credits

## Art

All current visuals are original placeholder pixel art drawn directly in code
for this prototype. No third-party sprite sheets, tilesets, music, UI packs, or
Pokemon-related assets are included.

## Audio

No audio assets are included in this milestone build.

## Fonts

The prototype currently uses browser-available monospace fonts. No external
font files are bundled yet.

## Legal note

Tiamat is an original creature adventure project inspired by the broad feel of
late-1990s handheld RPGs. It does not include copyrighted Pokemon characters,
names, sprites, maps, UI assets, music, or sound effects.
